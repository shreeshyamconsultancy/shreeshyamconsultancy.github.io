Free publishing option:
1. Create/sign in to a GitHub account.
2. Create a public repository named shree-shyam-consultancy.
3. Upload index.html to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for the Pages deployment and open the URL shown on the Pages settings screen.
